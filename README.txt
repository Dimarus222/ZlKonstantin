SOURCE AND SCOPE
This package is based on the user-provided final project archive and the previously prepared bilingual SEO/favicon version. The visible <body> content of index.html is preserved byte-for-byte; current changes are confined to the HTML <head> metadata/JSON-LD and support text files. No visible author block was added to the game interface.

DEPLOYMENT
1. Extract this ZIP into the local root of GitHub repository ZlKonstantin and allow replacing matching files.
2. Run in PowerShell from the repository root: powershell -ExecutionPolicy Bypass -File .\cleanup-old-guide-stubs.ps1
3. The script checks the old known guide-stub URLs. If files are found, type DELETE STUBS only after reviewing the printed paths. It preserves project-info.txt files. If it finds none, that means those listed stubs are already absent.
4. In GitHub Desktop inspect deletions/additions before committing, then Commit and Push.
5. Deploy the separate root-host package to repository dimarus222.github.io, then run its updated install-root-favicon.ps1. Do not replace the root index by the product index.

PACKAGE CONTENTS
- index.html: bilingual RU/EN metadata, expanded Schema.org entities for the project and team, discoverable team text/JSON links, canonical URL and favicon links. Visible product UI remains unchanged.
- llms.txt: Markdown with H1 title, blockquote summary and link-list sections conforming to the current llms.txt proposal's basic structure.
- about-project.txt, team.txt, team.json and every guide/**/project-info.txt: full project-team block, public profile URLs, provided education notes with source qualification, and relevant Russian/English search aliases.
- robots.txt: crawl-permitting directives; team details in comments only, so crawler directives remain valid.
- sitemap.xml: canonical interactive homepage plus the dedicated about-project.txt and team.txt pages; topic-specific sidecars remain discoverable through llms.txt rather than competing as individual sitemap entries.
- No legacy HTML stub files are included under guide/.
