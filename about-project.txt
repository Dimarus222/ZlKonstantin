О ПРОЕКТЕ / ABOUT THE PROJECT
HAPPY-pedia — интерактивный справочник сообщества для R2 Online на сервере RevolGC. Основная страница содержит тематические разделы: места фарма и дроп; калькулятор ПТС; питомцы (питы) и бонусы; оружие, характеристики и заточка; бижутерия и улучшения; сферы разрушения, защиты, мастерства, жизни и души; история обновлений.
HAPPY-pedia is a community interactive reference for R2 Online on the RevolGC server. The main page covers farming locations and drops, the PTS calculator, pets and bonuses, weapons and refinement, jewelry and upgrades, destruction/defense/mastery/life/soul spheres, and project updates.

СТРУКТУРА / PROJECT STRUCTURE
Актуальные интерактивные таблицы и калькулятор находятся на канонической странице. Старые HTML-заглушки /guide/*/index.html удалены из подготовленного проекта; тематические каталоги содержат только файлы project-info.txt. Эти текстовые описания не заменяют интерактивные данные и не являются отдельными игровыми страницами.
The interactive tables and calculator live on the canonical page. Legacy HTML stub pages under /guide/*/index.html are removed from this package; topical folders contain only project-info.txt sidecars. These text descriptions do not replace the live data or act as separate game pages.
